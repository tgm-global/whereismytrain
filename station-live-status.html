Station Live Status & Departure Board

Pick a station and a time window to list the trains scheduled to stop there today, sorted by time.

How the station board works

The board compares the current time on your device with the scheduled arrival and departure of every train that halts at the station and keeps only trains that run on today’s weekday. Trains that start or end at the station are marked.

It is a planning aid: delays, cancellations and platform changes are published live on NTES. Every station also has its own page with the complete day-wise time table – see the station list.

Useful for

  • Knowing how many trains you can catch in the next few hours.
  • Checking trains that start from a station and the ones that terminate there.
  • Finding the busiest hours before heading to the station.

Frequently asked questions

Is this a live arrival board?

It is a schedule-based board. Actual arrival times can differ; use the official NTES station enquiry for live delays.

What is a station code?

Every railway station has a short code, for example NDLS for New Delhi, CSMT for Mumbai CSMT and MAS for Chennai Central. You can search by name or by code.

Which trains are listed?

Trains that halt at the station and run on the current weekday, taken from the timetable feed.
