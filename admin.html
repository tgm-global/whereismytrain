Update timetable data

Upload a new GTFS feed and the site rebuilds itself: data files, every train, station and route page, sitemaps and the app cache.

How it works

  1. Download the latest feed ZIP from the Mobility Database feed page (button “Download latest dataset”).
  2. Choose that ZIP below. It is checked in your browser first.
  3. Press Upload and rebuild. The ZIP is committed to your GitHub repository and a GitHub Action converts it and republishes the site (usually 3 to 8 minutes).

You need a GitHub token once: GitHub → Settings → Developer settings → Fine-grained tokens → repository access: only this repo → permissions Contents: Read and write and Actions: Read and write. The token is used only to talk to api.github.com from this page.

Upload a feed ZIP

Or: rebuild from a direct feed link

Paste the direct download link of the feed ZIP (copy it from the Mobility Database download button). GitHub downloads it itself, so you do not need to upload a large file.
